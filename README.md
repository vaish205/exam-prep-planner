# Exam Prep Planner

A study-planning and GATE CSE PYQ analysis application built using Python, Streamlit, MySQL, Pandas, and SQL.

The application helps users manage subjects, topics, exams, study schedules, and GATE CSE previous-year questions.

## Features

* Subject and topic management
* Exam and deadline management
* Automated study schedule generation
* GATE CSE PYQ CSV import
* Data cleaning and validation
* Duplicate question detection
* Topic-wise PYQ analysis
* Practice paper generation
* Frequency-based study recommendations
* Dashboard for study and PYQ statistics
* Automated testing
